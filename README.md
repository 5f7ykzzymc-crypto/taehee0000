# 작업시작 · 웹툰 스토리 스튜디오

맥에서 브라우저 없이 실행하는 조용한 글쓰기 앱입니다. 인터넷 연결이나 회원가입 없이 사용할 수 있습니다.

## 맥 앱 설치하기

1. 자신의 맥에 맞는 설치 파일을 받습니다. **Apple 메뉴 → 이 Mac에 관하여**에서 칩을 확인할 수 있습니다.
   - **M1·M2·M3·M4 등 Apple 칩:** [Apple Silicon용 DMG](https://github.com/5f7ykzzymc-crypto/taehee0000/releases/latest/download/work-start-mac-arm64.dmg)
   - **Intel 프로세서:** [Intel용 DMG](https://github.com/5f7ykzzymc-crypto/taehee0000/releases/latest/download/work-start-mac-x64.dmg)
2. DMG 파일을 열고 **작업시작.app**을 **응용 프로그램** 폴더로 드래그합니다.
3. 응용 프로그램 폴더에서 **작업시작**을 실행합니다. Dock에 고정해서 사용할 수도 있습니다.

초기 배포는 Apple 개발자 인증·공증을 거치지 않았습니다. macOS에서 실행을 차단하면 앱을 한 번 실행한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**로 허용하세요. 별도 개발 도구 설치는 필요하지 않습니다.

DMG 대신 압축 파일이 필요하면 [Apple Silicon용 앱 ZIP](https://github.com/5f7ykzzymc-crypto/taehee0000/releases/latest/download/work-start-mac-arm64.zip) 또는 [Intel용 앱 ZIP](https://github.com/5f7ykzzymc-crypto/taehee0000/releases/latest/download/work-start-mac-x64.zip)을 사용하세요. 소스 코드 ZIP과 달리 **작업시작.app**이 들어 있습니다.

## 기존 브라우저 원고를 앱으로 옮기기

1. 이전에 쓰던 브라우저 버전을 열고 왼쪽 아래 **전체 백업**으로 JSON 파일을 저장합니다.
2. 새 **작업시작.app**에서 **백업 불러오기**를 눌러 그 JSON 파일을 선택합니다.
3. 확인 창에서 불러오면 모든 작품의 원고·캐릭터·이미지가 함께 옮겨집니다.

브라우저와 앱의 저장 공간은 서로 다릅니다. 앱은 맥의 `~/Library/Application Support/YeobaekStoryStudio/`에 자동 저장합니다. 앱을 다른 폴더로 옮기거나 새 버전으로 교체해도 같은 저장 공간을 사용합니다. 중요한 원고는 **전체 백업** 파일로도 보관하세요.

## 기존 브라우저 버전 사용하기

윈도우나 이전 방식으로 사용하려면 [소스 ZIP](https://github.com/5f7ykzzymc-crypto/taehee0000/archive/refs/heads/main.zip)의 압축을 풀고 **작업시작.html**을 여세요. `app.js`, `typewriter.js`, `style.css`도 같은 폴더에 있어야 합니다. 맥 앱 설치에는 이 과정이 필요 없습니다.

## 글쓰기와 캐릭터 시트

- 왼쪽 **작품** 옆 **+**로 새 작품을 만듭니다. 작품 선택 목록으로 전환하고, 옆 연필 버튼으로 작품 이름을 바꿀 수 있습니다.
- 작품마다 에피소드·장면·캐릭터·이미지가 따로 보관됩니다. 새 작품은 빈 에피소드 하나로 시작하며, 기존에 작성한 자료는 첫 작품으로 그대로 이어집니다. 마지막으로 선택한 작품도 기억합니다.
- 왼쪽 카테고리에서 **글쓰기**와 **캐릭터 시트**를 전환합니다.
- 에피소드와 장면을 추가하고 제목·원고를 작성하세요. 에피소드 소개는 제목 옆 **소개** 버튼으로 펼쳐 편집합니다. 집중 모드, 다크 모드, 글자 크기를 조절할 수 있습니다.
- 에피소드·장면 카드를 드래그하거나, 오른쪽 점 모양 핸들을 잡아 위아래로 옮기면 순서가 자동 저장됩니다. 핸들에 키보드 포커스를 두고 위·아래 방향키 또는 Home·End 키로 이동할 수도 있습니다.
- 카드에 마우스를 올리면 나타나는 휴지통으로 에피소드·장면을 삭제합니다. 확인 창에서 삭제하며, 마지막 항목을 삭제하면 빈 에피소드·장면 하나를 남깁니다. 다른 작품의 자료는 유지됩니다.
- 제목과 본문은 맥 메모 앱처럼 시스템 고딕체로 표시됩니다. 맥은 Apple 시스템 글꼴, 윈도우는 Segoe UI·맑은 고딕을 사용하며, 기존에 선택한 글자 크기는 유지됩니다.
- 캐릭터 시트에는 이름, 역할, 나이, 외형, 성격, 배경, 목표, 관계, 메모를 정리할 수 있습니다.

## 집중 모드와 사이드바

- 상단 왼쪽의 두 패널 버튼으로 **에피소드 목록**과 **장면 구성**을 각각 접거나 펼칩니다. 집중 모드와 별개로 동작하며, 두 패널의 상태를 같은 브라우저에 기억합니다.
- **집중 모드**는 양쪽 목록을 숨기고 브라우저 전체 화면을 요청합니다. **집중 종료** 버튼이나 **Esc**로 종료하면 이전 사이드바 상태로 돌아옵니다.
- 브라우저가 전체 화면을 허용하지 않는 경우에도 원고 집중 화면은 유지됩니다. 이때 브라우저 메뉴에서 전체 화면을 선택할 수 있습니다.
- Safari는 전체 화면에서도 설정에 따라 주소줄을 표시할 수 있습니다. 계속 보이면 Safari의 **보기** 메뉴에서 전체 화면 도구 막대를 항상 표시하는 옵션을 꺼주세요. 마우스를 화면 위쪽으로 올리면 브라우저 도구 막대가 잠시 나타날 수 있습니다.

## 타자기 모드 · 이름 바꾸기

- 상단의 **타자기 모드**를 켜면 커서가 있는 줄이 원고 화면의 중앙에 머무릅니다. 별도 입력 테두리 없이 줄바꿈·자동 줄바꿈을 따라가며, 전체 화면 집중 모드와 별도로 켜고 끌 수 있습니다.
- 제목과 장면 정보는 원고 상단에 표시되고, 중앙 정렬을 위한 여백은 본문 앞에만 적용됩니다.
- 스크롤로 앞부분을 읽는 동안에는 강제로 되돌리지 않고, 원고에서 다시 입력하거나 커서를 움직이면 중앙을 맞춥니다. 한글 조합 중에는 화면 이동을 잠시 멈춥니다.
- 켜짐 상태는 같은 브라우저에서 기억합니다. 다시 열었을 때에는 입력창에 포커스를 주면 동작합니다.
- 왼쪽 위 **여백** 이름 또는 연필 아이콘을 누르면 작업실 이름을 바꿀 수 있습니다. 최대 30자이며, 왼쪽 이름·브라우저 탭·전체 백업 이름에 반영됩니다. 바꾼 이름은 자동 저장되고 JSON 백업에도 포함됩니다.

## 이미지 넣기

캐릭터 시트나 글쓰기 장면을 열고 이미지를 복사한 뒤 **Ctrl+V**(윈도우) 또는 **⌘V**(맥)를 누르세요. 글쓰기에서는 별도 이미지 항목이나 버튼 없이 현재 장면의 원고 아래에 이미지가 나타납니다. 원고에 이미지 파일을 끌어놓아도 됩니다. 캐릭터 시트에서는 **이미지 추가** 버튼으로 파일을 선택하거나 캐릭터 이미지 영역에 파일을 끌어놓을 수도 있습니다.

이미지는 캐릭터·장면마다 최대 6장입니다. 저장 공간을 아끼기 위해 긴 변을 최대 1,200픽셀로 줄여 저장합니다. GIF는 움직이지 않는 이미지로 저장됩니다. 중요한 원본은 따로 보관하세요.

## 기존 브라우저 버전의 실행 파일 이름이 바뀐 경우

새 실행 파일은 **작업시작.html**입니다. 기존 **index.html**도 같은 앱을 여는 호환 파일로 남겨 두었습니다. 저장 위치가 파일 이름에 따라 구분되는 브라우저가 있으므로, 업데이트 전 기존 앱에서 **전체 백업**을 받고 작업시작.html을 연 뒤 **백업 불러오기**로 옮겨 주세요. 기존 원고가 바로 보이지 않으면 기존 index.html을 열어 백업할 수 있습니다.

## 저장·백업·다른 컴퓨터로 옮기기

원고와 이미지는 **현재 앱에 자동 저장**됩니다. 기존 브라우저 버전에서는 해당 브라우저에 저장합니다. 기기 사이에 자동 동기화되지는 않습니다. 이전 버전의 `yeobaek-v1` 원고는 기존 브라우저에서 불러온 뒤 전체 백업으로 앱에 옮길 수 있습니다.

- **전체 백업**으로 JSON 파일을 저장하면 모든 작품의 이름·에피소드·캐릭터·이미지를 함께 보관할 수 있습니다.
- 다른 컴퓨터에서 앱을 열고 **백업 불러오기**로 그 JSON 파일을 선택하면 작업을 옮길 수 있습니다. 복원 전에는 현재 작업도 백업하세요.
- 새 전체 백업을 불러오면 모든 작품을 백업 내용으로 교체합니다. 이전 버전의 단일 작품 백업은 현재 선택한 작품에만 적용하며, 다른 작품은 유지합니다.
- **Markdown 내보내기**는 현재 작업을 읽을 수 있는 문서로 저장하며 이미지도 포함합니다. 작업을 그대로 옮기려면 전체 JSON 백업을 사용하세요.

**업데이트 ZIP의 압축을 풀기 전에 전체 백업을 별도 폴더에 저장하세요.** 이전 버전에 전체 백업 버튼이 없다면, 먼저 에피소드마다 내보내기로 원고를 보관하세요. 그다음 새 ZIP의 앱 파일을 기존 앱과 같은 폴더에 덮어쓰고 같은 브라우저에서 열면 이전 원고를 불러옵니다. 앱 폴더의 위치·파일 경로, 브라우저 또는 브라우저 프로필이 바뀌면 저장된 작업이 보이지 않을 수 있습니다. 브라우저 데이터 삭제·시크릿 모드도 저장에 영향을 줍니다. 백업 JSON에는 원고와 이미지가 들어 있으므로 개인 파일처럼 보관하세요.

## 개발 검증

배포된 맥 앱 사용에는 패키지 설치가 필요 없습니다. 개발하려면 Node.js 22.12 이상에서 다음을 실행하세요.

```sh
npm ci
npm run desktop:dev
npm run test:desktop
```

맥에서 `npm run desktop:mac`을 실행하면 `dist/`에 Apple Silicon·Intel용 DMG와 앱 ZIP이 생성됩니다. `v`로 시작하는 버전 태그를 올리면 GitHub Actions의 macOS 환경에서 앱 검사·패키징 후 GitHub Release에 설치 파일을 게시합니다. 이 초기 빌드는 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다.

맥 앱은 Electron의 격리된 렌더러와 로컬 리소스만 사용합니다. 원고 화면에 Node.js 권한을 노출하지 않고, 외부 페이지 이동과 새 창을 차단합니다. 백업·내보내기는 맥의 파일 저장 창을 사용합니다.

브라우저 통합 검증은 `npm ci`로 개발용 Playwright를 설치하고 Chromium을 준비한 환경에서 실행합니다.

```sh
node --test tests/browser.test.cjs
```

저장·백업·복원, 이미지 붙여넣기, 집중 모드, 타자기 모드, 이름 변경을 검증합니다. 테스트는 자체 임시 HTTP 서버를 사용합니다. 로컬 개발 서버가 필요하면 `python3 -m http.server 3000`으로 실행할 수 있습니다.

실행 화면의 HTML 원본은 `작업시작.html`입니다. 수정 후 아래를 실행하면 기존 경로용 `index.html`도 같은 내용으로 갱신됩니다. 빌드는 파일 복사만 수행하며 패키지 설치가 필요 없습니다.

```sh
node tools/sync-entry.mjs
```

`npm run build`로도 같은 작업을 실행할 수 있습니다.
