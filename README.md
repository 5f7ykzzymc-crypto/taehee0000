# 여백 · 웹툰 스토리 스튜디오

윈도우와 맥에서 사용할 수 있는 조용한 글쓰기 공간입니다. 별도 설치나 회원가입 없이 브라우저에서 실행됩니다.

## 처음 실행하기

1. [앱 ZIP 다운로드](https://github.com/5f7ykzzymc-crypto/taehee0000/archive/refs/heads/main.zip)를 누릅니다. 저장소가 비공개라면 GitHub에 먼저 로그인하세요.
2. ZIP 파일의 압축을 풉니다.
3. 폴더 안의 **index.html**을 더블 클릭합니다. Chrome·Edge·Safari 등 최신 브라우저를 사용하세요.

폴더 안의 파일을 함께 보관해야 화면과 기능이 정상적으로 작동합니다. 앱 실행에 별도 프로그램이나 패키지 설치는 필요하지 않습니다.

## 글쓰기와 캐릭터 시트

- 왼쪽 카테고리에서 **글쓰기**와 **캐릭터 시트**를 전환합니다.
- 에피소드와 장면을 추가하고 제목·소개·원고를 작성하세요. 집중 모드, 다크 모드, 글자 크기를 조절할 수 있습니다.
- 캐릭터 시트에는 이름, 역할, 나이, 외형, 성격, 배경, 목표, 관계, 메모를 정리할 수 있습니다.

## 집중 모드와 사이드바

- 상단 왼쪽 **사이드바 접기 / 펼치기** 버튼으로 카테고리와 장면 목록을 함께 숨기거나 표시합니다. 집중 모드와 별개로 동작하며, 접은 상태도 같은 브라우저에 기억합니다.
- **집중 모드**는 양쪽 목록을 숨기고 브라우저 전체 화면을 요청합니다. **집중 종료** 버튼이나 **Esc**로 종료하면 이전 사이드바 상태로 돌아옵니다.
- 브라우저가 전체 화면을 허용하지 않는 경우에도 원고 집중 화면은 유지됩니다. 이때 브라우저 메뉴에서 전체 화면을 선택할 수 있습니다.
- Safari는 전체 화면에서도 설정에 따라 주소줄을 표시할 수 있습니다. 계속 보이면 Safari의 **보기** 메뉴에서 전체 화면 도구 막대를 항상 표시하는 옵션을 꺼주세요. 마우스를 화면 위쪽으로 올리면 브라우저 도구 막대가 잠시 나타날 수 있습니다.

## 이미지 넣기

캐릭터 시트나 글쓰기 장면을 열고 이미지를 복사한 뒤 **Ctrl+V**(윈도우) 또는 **⌘V**(맥)를 누르세요. 현재 캐릭터 또는 현재 장면의 참고 이미지 영역에 들어갑니다. 파일 선택이나 이미지 파일 끌어놓기도 가능합니다.

이미지는 캐릭터·장면마다 최대 6장입니다. 저장 공간을 아끼기 위해 긴 변을 최대 1,200픽셀로 줄여 저장합니다. GIF는 움직이지 않는 이미지로 저장됩니다. 중요한 원본은 따로 보관하세요.

## 맞춤법 검사와 수정

글쓰기 화면의 **맞춤법 검사·수정** 버튼을 누르면 내장 Hunspell 엔진과 한국어 사전으로 현재 장면을 검사합니다. 사전에 없는 단어·용언 활용형을 찾고 수정 후보를 보여 줍니다. `먹엇다 → 먹었다`, `않녕하세요 → 안녕하세요`, `밥을먹었다 → 밥을 먹었다` 같은 오류를 확인할 수 있습니다. 처음 검사할 때 약 2MB의 로컬 엔진·사전 파일을 읽으므로 잠시 기다려 주세요. 검사 중에도 창을 닫아 취소할 수 있습니다.

- 후보를 선택하고 **수정**을 누르거나 **선택한 제안 모두 수정**으로 적용하세요. 추천 후보가 없으면 수정안을 직접 입력할 수 있습니다.
- 마지막 수정은 되돌릴 수 있으며, 수정 후 다시 검사합니다.
- **이번만 넘기기**는 현재 검사 창에서만 제외합니다.
- **사전에 추가**는 해당 단어를 작업 자료에 보관합니다. 등록된 단어는 검사 창의 **나만의 사전**에서 삭제할 수 있고, 전체 백업에도 포함됩니다.
- 캐릭터 시트의 이름과 흔한 조사 조합은 자동으로 제외합니다.
- 검사가 실패하면 이유와 **다시 검사** 버튼을 표시합니다. 실패를 ‘오타 없음’으로 표시하지 않습니다.

원고는 외부로 전송하지 않으며 검사에는 API 키나 인터넷 연결이 필요하지 않습니다. 별도 회원가입·검사료도 없습니다. ZIP의 **vendor 폴더**와 **spell-engine.js**를 포함해 앱 파일을 모두 함께 보관하세요. 최신 Safari·Chrome·Edge를 권장합니다. 워커 또는 WebAssembly 실행이 제한된 브라우저에서는 오류 안내가 나타납니다.

사전은 국립국어원 단어 데이터를 포함한 공개 **hunspell-dict-ko 0.7.94**입니다. 국립국어원이 직접 제공하는 검사 API는 아닙니다. 단어 기반 검사이므로 모든 문맥·문법·띄어쓰기 오류를 찾아내지는 못합니다. 고유명사와 대사는 작가가 확인하고 적용해 주세요. 기존 12개 오타 규칙도 사전 검사와 함께 보완적으로 사용합니다. 출처와 라이선스, 대응 소스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 정리했습니다.

## 저장·백업·다른 컴퓨터로 옮기기

원고와 이미지는 **현재 브라우저에 자동 저장**됩니다. 윈도우와 맥 사이에 자동 동기화되지는 않습니다. 이전 버전의 `yeobaek-v1` 원고는 같은 브라우저 저장 공간에서 불러옵니다.

- **전체 백업**으로 JSON 파일을 저장하면 에피소드·캐릭터·이미지·나만의 사전을 함께 보관할 수 있습니다.
- 다른 컴퓨터에서 앱을 열고 **백업 불러오기**로 그 JSON 파일을 선택하면 작업을 옮길 수 있습니다. 복원 전에는 현재 작업도 백업하세요.
- **Markdown 내보내기**는 현재 작업을 읽을 수 있는 문서로 저장하며 이미지도 포함합니다. 작업을 그대로 옮기려면 전체 JSON 백업을 사용하세요.

**업데이트 ZIP의 압축을 풀기 전에 전체 백업을 별도 폴더에 저장하세요.** 이전 버전에 전체 백업 버튼이 없다면, 먼저 에피소드마다 내보내기로 원고를 보관하세요. 그다음 새 ZIP의 앱 파일을 기존 앱과 같은 폴더에 덮어쓰고 같은 브라우저에서 열면 이전 원고를 불러옵니다. 앱 폴더의 위치·파일 경로, 브라우저 또는 브라우저 프로필이 바뀌면 저장된 작업이 보이지 않을 수 있습니다. 브라우저 데이터 삭제·시크릿 모드도 저장에 영향을 줍니다. 백업 JSON에는 원고와 이미지가 들어 있으므로 개인 파일처럼 보관하세요.

## 개발 검증

앱 사용에는 패키지 설치가 필요 없습니다. 엔진과 사전 배포본이 포함되어 있습니다. Node.js가 설치되어 있다면 기본 오타 검수 테스트를 실행할 수 있습니다.

```sh
node --test tests/proofread.test.cjs
```

브라우저 통합 검증은 개발용 Playwright와 Chromium을 설치한 환경에서 실행합니다.

```sh
node --test tests/browser.test.cjs
```

로컬 개발 서버는 `python3 -m http.server 3000`으로 실행할 수 있습니다. 브라우저 테스트는 자체 임시 서버를 사용합니다.

검사 엔진을 다시 빌드하는 개발 작업에는 고정된 개발 의존성을 사용합니다.

```sh
npm ci
npm run build:spellcheck
```

Playwright가 설치된 환경에서는 실제 한국어 사전과 WASM 엔진을 실행하는 브라우저 테스트로 후보 선택·수정·되돌리기·개인 사전·취소·오류 복구를 검증합니다.
