# 여백 · 웹툰 스토리 스튜디오

윈도우와 맥에서 사용할 수 있는 조용한 글쓰기 공간입니다. 별도 설치나 회원가입 없이 브라우저에서 실행됩니다.

## 처음 실행하기

1. [앱 ZIP 다운로드](https://github.com/5f7ykzzymc-crypto/taehee0000/archive/refs/heads/main.zip)를 누릅니다. 저장소가 비공개라면 GitHub에 먼저 로그인하세요.
2. ZIP 파일의 압축을 풉니다.
3. 폴더 안의 **작업시작.html**을 더블 클릭합니다. Chrome·Edge·Safari 등 최신 브라우저를 사용하세요.

폴더 안의 파일을 함께 보관해야 화면과 기능이 정상적으로 작동합니다. 앱 실행에 별도 프로그램이나 패키지 설치는 필요하지 않습니다.

## 글쓰기와 캐릭터 시트

- 왼쪽 카테고리에서 **글쓰기**와 **캐릭터 시트**를 전환합니다.
- 에피소드와 장면을 추가하고 제목·원고를 작성하세요. 에피소드 소개는 제목 옆 **소개** 버튼으로 펼쳐 편집합니다. 집중 모드, 다크 모드, 글자 크기를 조절할 수 있습니다.
- 캐릭터 시트에는 이름, 역할, 나이, 외형, 성격, 배경, 목표, 관계, 메모를 정리할 수 있습니다.

## 집중 모드와 사이드바

- 상단 왼쪽의 두 패널 버튼으로 **에피소드 목록**과 **장면 구성**을 각각 접거나 펼칩니다. 집중 모드와 별개로 동작하며, 두 패널의 상태를 같은 브라우저에 기억합니다.
- **집중 모드**는 양쪽 목록을 숨기고 브라우저 전체 화면을 요청합니다. **집중 종료** 버튼이나 **Esc**로 종료하면 이전 사이드바 상태로 돌아옵니다.
- 브라우저가 전체 화면을 허용하지 않는 경우에도 원고 집중 화면은 유지됩니다. 이때 브라우저 메뉴에서 전체 화면을 선택할 수 있습니다.
- Safari는 전체 화면에서도 설정에 따라 주소줄을 표시할 수 있습니다. 계속 보이면 Safari의 **보기** 메뉴에서 전체 화면 도구 막대를 항상 표시하는 옵션을 꺼주세요. 마우스를 화면 위쪽으로 올리면 브라우저 도구 막대가 잠시 나타날 수 있습니다.

## 타자기 모드 · 이름 바꾸기

- 상단의 **타자기 모드**를 켜면 커서가 있는 줄이 원고 화면의 중앙에 머무릅니다. 별도 입력 테두리 없이 줄바꿈·자동 줄바꿈을 따라가며, 전체 화면 집중 모드와 별도로 켜고 끌 수 있습니다.
- 제목과 장면 정보는 원고 상단에 표시되고, 중앙 정렬을 위한 여백은 본문 앞에만 적용됩니다.
- 스크롤로 앞부분을 읽는 동안에는 강제로 되돌리지 않고, 원고에서 다시 입력하거나 커서를 움직이면 중앙을 맞춥니다. 한글 조합 중에는 화면 이동을 잠시 멈춥니다.
- 켜짐 상태는 같은 브라우저에서 기억합니다. 다시 열었을 때에는 입력창에 포커스를 주면 동작합니다.
- 왼쪽 위 **여백** 이름 또는 연필 아이콘을 누르면 작업실 이름을 바꿀 수 있습니다. 최대 30자이며, 왼쪽 이름·브라우저 탭·전체 백업 이름에 반영됩니다. 바꾼 이름은 자동 저장되고 JSON 백업에도 포함됩니다.

## 이미지 넣기

캐릭터 시트나 글쓰기 장면을 열고 이미지를 복사한 뒤 **Ctrl+V**(윈도우) 또는 **⌘V**(맥)를 누르세요. 글쓰기에서는 별도 이미지 항목이나 버튼 없이 현재 장면의 원고 아래에 이미지가 나타납니다. 원고에 이미지 파일을 끌어놓아도 됩니다. 캐릭터 시트에서는 **이미지 추가** 버튼으로 파일을 선택하거나 캐릭터 이미지 영역에 파일을 끌어놓을 수도 있습니다.

이미지는 캐릭터·장면마다 최대 6장입니다. 저장 공간을 아끼기 위해 긴 변을 최대 1,200픽셀로 줄여 저장합니다. GIF는 움직이지 않는 이미지로 저장됩니다. 중요한 원본은 따로 보관하세요.

## 실행 파일 이름이 바뀐 경우

새 실행 파일은 **작업시작.html**입니다. 기존 **index.html**도 같은 앱을 여는 호환 파일로 남겨 두었습니다. 저장 위치가 파일 이름에 따라 구분되는 브라우저가 있으므로, 업데이트 전 기존 앱에서 **전체 백업**을 받고 작업시작.html을 연 뒤 **백업 불러오기**로 옮겨 주세요. 기존 원고가 바로 보이지 않으면 기존 index.html을 열어 백업할 수 있습니다.

## 저장·백업·다른 컴퓨터로 옮기기

원고와 이미지는 **현재 브라우저에 자동 저장**됩니다. 윈도우와 맥 사이에 자동 동기화되지는 않습니다. 이전 버전의 `yeobaek-v1` 원고는 같은 브라우저 저장 공간에서 불러옵니다.

- **전체 백업**으로 JSON 파일을 저장하면 에피소드·캐릭터·이미지를 함께 보관할 수 있습니다.
- 다른 컴퓨터에서 앱을 열고 **백업 불러오기**로 그 JSON 파일을 선택하면 작업을 옮길 수 있습니다. 복원 전에는 현재 작업도 백업하세요.
- **Markdown 내보내기**는 현재 작업을 읽을 수 있는 문서로 저장하며 이미지도 포함합니다. 작업을 그대로 옮기려면 전체 JSON 백업을 사용하세요.

**업데이트 ZIP의 압축을 풀기 전에 전체 백업을 별도 폴더에 저장하세요.** 이전 버전에 전체 백업 버튼이 없다면, 먼저 에피소드마다 내보내기로 원고를 보관하세요. 그다음 새 ZIP의 앱 파일을 기존 앱과 같은 폴더에 덮어쓰고 같은 브라우저에서 열면 이전 원고를 불러옵니다. 앱 폴더의 위치·파일 경로, 브라우저 또는 브라우저 프로필이 바뀌면 저장된 작업이 보이지 않을 수 있습니다. 브라우저 데이터 삭제·시크릿 모드도 저장에 영향을 줍니다. 백업 JSON에는 원고와 이미지가 들어 있으므로 개인 파일처럼 보관하세요.

## 개발 검증

앱 사용에는 패키지 설치가 필요 없습니다. 실행 파일과 `app.js`, `typewriter.js`, `style.css`를 같은 폴더에 보관하세요.

브라우저 통합 검증은 `npm ci`로 개발용 Playwright를 설치하고 Chromium을 준비한 환경에서 실행합니다.

```sh
node --test tests/browser.test.cjs
```

저장·백업·복원, 이미지 붙여넣기, 집중 모드, 타자기 모드, 이름 변경을 검증합니다. 테스트는 자체 임시 HTTP 서버를 사용합니다. 로컬 개발 서버가 필요하면 `python3 -m http.server 3000`으로 실행할 수 있습니다.

실행 화면의 HTML 원본은 `작업시작.html`입니다. 수정 후 아래를 실행하면 기존 경로용 `index.html`도 같은 내용으로 갱신됩니다. 빌드는 파일 복사만 수행하며 패키지 설치가 필요 없습니다.

```sh
node tools/sync-entry.mjs
```

`npm run build`로도 같은 작업을 실행할 수 있습니다.
